# 城市天气查询小程序 - 新手使用教程

## 一、功能介绍

这是一个基于 Python + Tkinter 开发的城市天气查询小程序，具有以下功能：

- ✅ 输入中文城市名，一键获取实时天气
- ✅ 可视化展示完整天气数据（温度、湿度、风向等）
- ✅ 一键复制天气信息到剪贴板
- ✅ 自动保存最近查询的10个城市，快速切换
- ✅ 友好的中文错误提示
- ✅ 本地保存API密钥，无需重复填写

---

## 二、环境要求

- **操作系统**：Windows / macOS / Linux
- **Python版本**：Python 3.6 及以上

## 三、依赖安装

### 方法一：使用 pip 安装（推荐）

打开命令行（Windows按 `Win+R`，输入 `cmd`），执行以下命令：

```bash
pip install requests
```

如果需要剪贴板增强功能（可选）：

```bash
pip install pyperclip
```

### 方法二：使用国内镜像加速安装

如果下载速度慢，可以使用国内镜像：

```bash
pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 验证安装

```bash
python -c "import requests; print('安装成功')"
```

## 四、获取高德地图API密钥

### 步骤1：注册账号

1. 访问高德地图开放平台：https://lbs.amap.com/
2. 点击右上角「注册」，完成账号注册

### 步骤2：实名认证

1. 登录后进入「控制台」
2. 完成个人实名认证（需要身份证信息）

### 步骤3：创建应用

1. 进入「应用管理」→「我的应用」
2. 点击「创建新应用」
3. 填写应用名称（如：天气查询）
4. 应用类型选择：其他

### 步骤4：添加Key

1. 在刚创建的应用下，点击「添加Key」
2. 服务平台选择：**Web服务**
3. 提交后即可获得API密钥（Key）

### 免费额度说明

高德地图个人开发者每天可免费调用天气API **5000次**，完全够个人使用。

## 六、使用指南

### 首次使用

1. 启动程序后，点击底部「⚙️ 设置」按钮
2. 输入你在高德地图申请的API密钥
3. 点击「保存」，系统会自动验证密钥有效性
4. 验证成功后即可开始查询

### 查询天气

1. 在顶部输入框输入城市名称
   - 支持省份：北京、上海、广东...
   - 支持城市：广州、深圳、杭州...
   - 支持简称：京、沪、粤...
2. 点击「查询」按钮或按回车键
3. 等待几秒即可看到天气信息

### 快捷功能

- **历史记录**：点击历史城市按钮可快速查询
- **复制天气**：点击「📋 复制天气」按钮复制天气信息
- **清空历史**：点击「🗑️ 清空历史」按钮清除历史记录

## 七、常见问题

### Q1：提示"请先设置API密钥"

**解决方法**：点击底部「设置」按钮，输入有效的高德地图API密钥

### Q2：提示"API密钥无效"

**解决方法**：
- 检查密钥是否正确复制
- 确认服务平台选择的是「Web服务」
- 确认密钥状态是否正常

### Q3：提示"未找到城市"

**解决方法**：
- 尝试输入完整的城市名称（如：广州市）
- 检查城市名称是否有错别字

### Q4：提示"网络连接失败"

**解决方法**：
- 检查电脑网络连接是否正常
- 检查防火墙是否拦截程序

### Q5：提示"API调用次数超限"

**解决方法**：
- 个人开发者每天5000次免费额度
- 次日0点自动重置额度

### Q6：双击文件闪退

**解决方法**：
- 使用命令行运行查看错误信息
- 确认Python已正确安装
- 确认requests库已安装

## 八、文件说明

程序运行后会在用户目录下创建配置文件夹：

- **Windows**：`C:\Users\你的用户名\.weather_app\`
- **macOS**：`/Users/你的用户名/.weather_app/`

配置文件：
- `config.json`：保存API密钥
- `history.json`：保存查询历史
